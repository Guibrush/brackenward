# T-0001 — Create the empty Godot project file

Owner: `eng/tools`

## Goal

A `project.godot` exists for the `brackenward` project so that the engine can import
headlessly and the import gate has something to check. No main scene, no gameplay,
no autoloads — this file makes the project *exist*, nothing more.

## Context

Read first:

- `docs/gates/G1-bootstrap.md` — criterion G1.6 is the definition of done
- `docs/STATE.md` — G0 is signed; G1 is the current milestone
- `docs/LESSONS.md` — **L-005** (`--import` alone exits 0 on a parse error) and **L-013** (run the gate script against your draft, not after)
- `scripts/gate/import.ps1` — read it before you write anything; it defines what passes

Godot 4.7.2 is installed at `%LOCALAPPDATA%\Programs\Godot\4.7.2\`. Headless commands
must use `Godot_v4.7.2-stable_win64_console.exe` or stdout is empty.

## Constraints

- You may write: `project.godot`
- You may create: `.gitignore` entries for engine cache **only if** `.gitignore` exists and lacks them; if it does not exist, report that instead of creating it (no owner yet)
- Do not touch: `docs/**`, `art/**`, `scripts/**`, anything under `.github/`
- Budget: no paid generation; nothing in this task costs money

## Definition of done

1. `project.godot` exists, with `config_version=5` and a `config/name` of `brackenward`.
2. It declares **no** main scene and **no** autoloads — G2 creates the main scene.
3. `powershell -NoProfile -File scripts/gate/import.ps1` exits 0, with both the
   `--import` pass and the per-script `--check-only` pass reported.
4. The engine creates `.godot/` on import; confirm whether `.gitignore` already
   excludes it, and report the answer with evidence either way.

## Do not

- Do not add a main scene, a scene file, or any script.
- Do not change `scripts/gate/import.ps1` to make it pass. If it fails for a reason
  you believe is a gate bug, stop and report — do not edit the gate.
- Do not run `git init` or create a repository; that is T-0003.
