# T-0006 — Make the secret scanner actually scan

Owner: `eng/tools`
Milestone: G1 — Bootstrap (blocking the signature)
Branch: `task/T-0006-secrets-scan`
Status: open

## Goal

`scripts/gate/secrets.ps1` produces a truthful result. Today it reports
"94 files scanned" and scans **zero** of them: a tracked file containing
`AKIA-EXAMPLE-NOT-A-KEY` passes G1.9. Until this is fixed, the G1.9 evidence in
`docs/gates/G1-result.md` is a false pass and G1 cannot be signed on it.

## Root cause (confirmed, not hypothesised)

`secrets.ps1:29` builds `$files` by `Join-Path` over `git ls-files` output, which
yields **strings**, not `FileInfo` objects. Then:

- line 40: `$f.Extension.ToLower()` — `Extension` does not exist on a string, so it
  is `$null`, and `.ToLower()` throws `You cannot call a method on a null-valued
  expression` once per file;
- line 45: `Get-Content $f.FullName` — `FullName` is also `$null`, so this throws too
  and is swallowed by `catch { continue }`.

Net effect: `$scanned++` counts every file, the regex loop never runs, `$findings`
stays empty, and line 57 prints a pass with a plausible count. The `Get-ChildItem`
fallback at line 33 uses real `FileInfo` and works — which is why the check was
genuine before the repository existed and became vacuous the moment it did.

## Required evidence — the check must fail before it may pass

1. Plant a probe: a tracked file containing `AKIA-EXAMPLE-NOT-A-KEY`, `git add` it,
   run the gate, and confirm it **fails** with the finding naming that file. Remove
   the probe and confirm unstage/cleanup leaves `git status` clean.
2. Also confirm the skip list works after the fix: a tracked binary asset (for
   example a `.png` under `art/style/`) must be skipped by extension rather than
   read as text.
3. Confirm stderr is silent: no "cannot call a method" blocks, exit 0 on the clean
   tree, and both G1.9 and G1.10 still pass.

## Constraints

- Write `scripts/gate/secrets.ps1` only.
- **Do not weaken the patterns.** The regex list stays exactly as it is; add a
  pattern only if you can justify it as a real key format.
- Do not change the gate criteria. G1.9 still means "no key-shaped strings in
  tracked files".
- Do not commit the probe file. It must never reach the remote.
- Follow L-017: the brief is not done at "file fixed". Commit, push, open the PR,
  and verify the remote branch exists. Do not merge — that is studio-lead's step.

## Definition of done

1. The scanner resolves real file objects and its `$scanned` count reflects files
   whose contents were actually regex-tested. State the count on the clean tree.
2. The planted-secret test fails the gate, and the failure names the file.
3. The clean tree passes, stderr silent, exit 0.
4. `powershell -NoProfile -File scripts/gate/all.ps1 -Gate G1` is green afterwards.
5. Committed on `task/T-0006-secrets-scan`, pushed, PR opened against `dev`,
   `gh api repos/Guibrush/brackenward/branches/task/T-0006-secrets-scan` returns 200.

## Return

The standard envelope. EVIDENCE must contain: the failing probe run (exit 1, finding
text), the clean run (exit 0, count), the `all.ps1` summary, the commit hash, and the
remote-branch check.
