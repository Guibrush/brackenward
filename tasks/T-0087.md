# T-0087 — A tower in hand can buy its next tier

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2H — inventory interaction
Status: open

## Problem

The tower window shows `Upgrade tier - place this tower to price it` for a tower in the
inventory. That was never asked for. A tower in hand should be upgradeable outside a
wave, priced from the same table a placed tower uses.

The price currently lives only on the placed `Tower` node (`tier_upgrade_cost`), so an
inventory instance has no cost and the window refuses it. The arena already owns the
tower scene; give it a way to price a tier without placing a node, and to upgrade an
in-hand instance with the same spend/refund rules as a placed one.

## Scope

1. `src/gameplay/arena.gd`:
   - cache the tower scene's `tier_upgrade_cost` once in `_ready` (instantiate one
     probe, copy the array, free it). Report the array in `ARENA_START`;
   - `upgrade_cost_for_tier(tier: int) -> int`: cost to reach `tier + 1`, -1 at the last
     tier or when there is no table;
   - `upgrade_inventory_tower(instance_id: int) -> bool`: refused during a wave, for an
     unknown or **placed** instance, at max tier, without the gold, or when the price is
     missing; otherwise spend through the ledger, call
     `inventory.raise_tower_tier(id)`, refund on refusal, and print
     `ARENA_UPGRADE_IN_HAND` with tier before/after, cost and gold.
2. `src/ui/tower_window.gd`:
   - `_tier_cost(tower)`: the placed node's `upgrade_cost()` when the tower is on the
     board, otherwise `arena.upgrade_cost_for_tier(tower.tier)`, otherwise -1;
   - use it in `state()["cost"]`, the tier row's label and `raise_tier()`;
   - `raise_tier()` calls `arena.upgrade_tower(node)` for a placed tower and
     `arena.upgrade_inventory_tower(id)` for one in hand - no `tier_in_hand_text`
     refusal. Keep the map/no-arena refusal (`tier_no_level_text`): the map has no level
     to price against;
   - delete `tier_in_hand_text`; change `tier_unpriced_text` to a map-only sentence
     (`Upgrade tier - open a level to price it`) used only when no arena is bound;
     `tier_max_row_text` still covers the last tier.
3. `src/ui/tests/inventory_migration_demo.gd`:
   - after the take-back (tower in hand, before the drag), give the run 100 gold through
     `run_state().add_gold()`, open the window on the in-hand tower, and assert:
     - the tier row reads `Upgrade to T2 - 60 gold` (priced, not "place this tower");
     - clicking it raises the instance to tier 2, costs exactly 60, the window shows
       `Tier T2`, and the bar's slot shows `T2`;
   - refresh the demo's `picked` dictionary's `tier_text` afterwards, so the later drag
     ghost/tower assertions expect T2 (the tower is placed at T2 later);
   - keep every existing case green.
