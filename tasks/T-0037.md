# T-0037 — Run lifecycle and currency

Owner: `eng/systems`
Milestone: G2 — Vertical slice
Wave: 2B — core systems
Status: open

## Goal

A run has a life: it starts, levels are completed in sequence, HQ health carries between
them, gold is earned and spent inside it, and losing a level ends the run.

## Context

Read first:

- `docs/CHARTER.md` — run structure: 5–10 levels, HQ health carries, failing a level ends
  the run, gold lives only inside a run
- `docs/adr/0002-g2-slice-is-a-full-run.md` — the slice is one complete run
- `src/gameplay/arena.gd`, `src/gameplay/hq.gd` — the existing contracts
- `docs/LESSONS.md` — L-033 (`--check-only` per script), L-035 (assert on output)

## Scope

- **Run state**: start, current level index, gold, HQ health carried across levels,
  defeat, completion.
- **Level transitions**: complete a level → advance with HQ and gold intact; the run ends
  at the boss level or when HQ reaches zero.
- **Gold**: earned on kill and on level completion, spent on towers and rerolls, reset at
  the start of a new run, never persisted.
- **Defeat**: HQ zero at any point ends the run; state says so plainly and cannot be
  continued.
- **Meta-progression persistence is deliberately out of scope** (deferred to G3). Unlocks
  at G2 are in-run only. Do not add a save file.

Expose this as a small state object that gameplay code queries, not as globals. Use
`PLACEHOLDER` markers for any numbers so T-0035's tables can replace them.

## Definition of done — with planted failures

1. `--check-only` output pasted for every script touched.
2. A headless run printing a three-level sequence: gold in, gold spent, HQ carried
   (e.g. 10 → 7 across levels), run completed. Paste the values.
3. **Planted failure A:** drive HQ to zero mid-run; the run must end, and subsequent level
   advancement must be refused with a reason. Show both.
4. **Planted failure B:** start a second run after defeat; gold and HQ must reset, not
   inherit. Show the before/after values.
5. **No save file exists** after a run — assert it explicitly, since persistence is
   deliberately deferred.

output, and `FILES TOUCHED`.
