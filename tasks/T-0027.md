## Goal

`scripts/gate/tests.ps1` runs an actual suite and fails when an assertion fails. The
gate exists but has nothing to run, so G2.9 reports `blocked`.

## Work

1. A minimal test runner that executes GDScript test files headless and reports one
   line per test, then a summary.
2. Three tests that exercise the main scene's contract, chosen because they already
   have known-good values:
   - a leak applies exactly `damage_per_leak` health (measured: 10 → 9)
   - the HQ reports depleted at zero health
   - a walker that reaches the end despawns rather than lingering
3. `tests.ps1` fails if any test fails, and prints the failing test's name.

## Definition of done — with a planted failure

1. Suite runs green; paste the per-test lines and the summary.
2. **Planted failure:** break one assertion on purpose (e.g. expect 2 damage instead
   of 1), show the run failing with that test named, restore, show green again.
3. A test that errors (parse error in a test file) is reported as a failure, not a
   silent skip.
