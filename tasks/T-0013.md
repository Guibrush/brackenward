# T-0013 — Parallel work without extra GitHub accounts

Owner: `eng/tools`
Milestone: G1 repair, before G2 wave 1
Branch: `task/T-0013-single-committer`
Status: done

## Goal

Let several specialists work at the same time in one checkout, by making
`studio-lead` the only process that writes to git.

## Context

Two agents cannot both commit in one working tree. Git serialises through
`.git/index.lock`, and concurrent `git switch` corrupts both agents' HEAD. That is
a property of the checkout, not of the GitHub identity: one credential can push any
number of branches concurrently.

Isolating git with worktrees was considered and rejected for now. Subagents inherit
the parent session's workspace, and every specialist's `edit` permission is scoped
to project-relative paths, so a subagent writing into `.worktrees/T-0011/assets/...`
is denied. Worktrees need either permission patterns rewritten with a leading
wildcard, or one session per worktree.

Parallelism does not require parallel git. The three wave-1 tasks write disjoint
paths, which `docs/OWNERSHIP.md` already guarantees. Only the commit is shared, and
a commit is fast.

## Change

- Deny `git add`, `git commit`, `git switch`, `git checkout`, and `git stash` on all
  nine write-capable specialists. Read-only inspection stays available for evidence.
- `studio-lead` gains a seven-step commit procedure: verify `FILES TOUCHED`, branch
  from `dev`, stage exactly the reported paths, commit with trailers, push, open a
  PR, merge serially when `mergeStateStatus` is `CLEAN`.
- Commits carry `Agent:` and `Task:` trailers, giving per-role attribution from
  `git log` without one GitHub account per agent.

## Definition of done

- No specialist can run a git write command; all can still run `status`, `diff`,
  `log`.
- The lead's integration section states the procedure unambiguously.
- `docs/GIT.md` documents who commits and why.
- Demonstrated from the next commit onwards by trailers appearing in `git log`.

## Do not

Do not remove read-only git access, and do not change any gate criterion.

## Return

Standard envelope.
