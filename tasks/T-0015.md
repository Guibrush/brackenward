# T-0015 — One real sound through the audio gate

Owner: `audio/sfx`
Milestone: G2 — Vertical slice
Wave: 1 — before any batch audio production
Branch: `task/T-0015-audio-probe`
Status: open

## Goal

One real ElevenLabs one-shot passes `scripts/gate/audio.ps1`. The audio gate has only
ever been run against fixtures; this proves the generator's actual output survives the
post step and the gate, before anyone spends a budget on 48 of them.

**Budget: 1 ElevenLabs call. Not 2, not 3.** If it fails, stop and report — do not
retry.

## Context

Read first:

- `docs/AUDIO.md` — formats, loudness targets, naming, loop policy
- `scripts/audio/gen-sfx.ps1`, `scripts/audio/post.ps1` — the pipeline
- `scripts/gate/audio.ps1`, `scripts/gate/gate.config.ps1` — the judge and its tolerance
- `docs/LESSONS.md` — **L-006** (single-pass loudnorm undershoots), **L-007** (measure
  the format you ship), **L-021** (an unobserved check is not evidence)

## The asset

A single placeholder one-shot, named per `docs/AUDIO.md`: `sfx_ui_click_01.wav`.
Purpose: UI click, 48 kHz, mono, short (`max_seconds` 1), −16 LUFS, ≤ −1 dBTP.

It is a **placeholder** and must be marked `"placeholder": true` in
`audio/manifest.json`. Nothing about it is final except whether it passes the gate.

## Constraints

- You may write: `assets/audio/sfx/sfx_ui_click_01.wav`, one entry in
  `audio/manifest.json` (your entries only — leave music entries alone), and scratch
  files in `%TEMP%`.
- Everything must pass through `scripts/audio/post.ps1`; nothing enters
  `assets/audio/` any other way.
- Do not create `assets/audio/music/` content; that is a different owner.
- Budget: 1 generation. Report actual spend even if it is 0.

## Definition of done

1. `audio/manifest.json` has one new `sfx` entry with the required fields (id, kind,
   file, loop false, target_lufs −16, max_seconds, license, prompt, generator, cost,
   `placeholder: true`).
2. The shipped file is `pcm_s16le` WAV, 48 kHz, mono, measured — paste the `ffprobe`
   output.
3. `powershell -NoProfile -File scripts/gate/audio.ps1` exits 0 with G2.7 passing.
   Paste the output.
4. Report the measured integrated loudness and true peak from the gate, and whether
   the post step needed a correction pass (L-006) to hit target.
5. If the gate rejects the real output for format, loudness, or peak, **stop**:
   report the exact rejection, do not retry, do not loosen the gate, and flag that
   all batch audio production is blocked pending a fix.
6. **Do not run any git command.** `studio-lead` is the only committer
   (`docs/GIT.md`); return `FILES TOUCHED` with exact paths, and the commits will
   carry `Agent: audio/sfx` and `Task: T-0015` trailers.

## Do not

- Do not add a second sound "to compare".
- Do not edit `audio.ps1` or its tolerances to make the file pass.
- Do not mark the asset final; it is a placeholder probe.
- Do not run `git add`, `git commit`, `git switch`, `git checkout`, or `git stash`.

## Return

The standard envelope with: actual spend, `ffprobe` output, gate output, measured
LUFS and dBTP, `FILES TOUCHED`, and an explicit one-line verdict on whether batch
audio can proceed.
