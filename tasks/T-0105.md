# T-0105 — Draw the enemy sprites on the lane

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

`scenes/enemy_walker.tscn` still draws polygons. Each enemy kind now has a shipped static
sprite set at `assets/art/enemies/<kind>/idle/{south,west,east,north}.png` (kinds:
grunt, runner, shieldback, swarmling, bloom, bulwark, herald, warden). Show the sprite for
the current facing and keep the polygons only as a fallback for an unknown kind.

## Scene and script

- `scenes/enemy_walker.tscn`: add a `Sprite2D` named `Sprite`, `visible = false`,
  `texture_filter = 1` (nearest), centered, before the Outline/Body polygons or above
  them; keep the polygons for the fallback.
- `src/gameplay/lane_walker.gd`:
  - `@export var kind: StringName = &"grunt"`, `@export var sprite_path: NodePath =
    ^"Sprite"`, `@export var sprite_format: String =
    "res://assets/art/enemies/%s/idle/%s.png"`.
  - Facing: update when the movement direction changes; the dominant axis wins (east for
    +x, west for -x, south for +y, north for -y), with the last facing kept on a tie.
  - `_apply_art()`: load the texture when `ResourceLoader.exists(sprite_format % [kind,
    facing])`; show the sprite and hide the polygons; otherwise show the polygons. Call it
    on setup and whenever the facing changes.
  - No change to health, speed, gold, arrival, or targeting.
- `src/gameplay/arena.gd` `spawn_from_entry()`: set the walker's `kind` from
  `entry.kind` before `adopt_walker()` (one line; the stats dict does not carry the kind).
- `src/gameplay/wave_entry.gd` stays untouched unless the kind cannot be read from
  `entry.kind`; report if so.

## Import and verification

- `Godot_v4.7.2-stable_win64_console.exe --headless --path . --import` for the new
  PNGs; include the generated `.import` files.
- `--check-only` both scripts; `tests.ps1` 6/6.
- Run `wave_demo.gd` (and `tower_demo.gd` if quick) — report any polygon-specific
  assertion rather than weakening it.
- A windowed frame with at least one enemy sprite and one tower sprite on the real level,
  outside the repo; re-run once on a windowed-only flake (L-043/L-044). Also a frame of
  the whole set if the art candidates are promoted.
- `git status --porcelain` and a clean-tree statement.

## Constraints

- Write `scenes/enemy_walker.tscn`, `src/gameplay/lane_walker.gd`, one line in
  `src/gameplay/arena.gd`, the generated `.import` files, and a demo only if its
  assertion is specifically about the old polygons.
- **30 steps, last 6 reserved**; no git; zero generations.

## Definition of done

- A known kind shows its facing texture at 1×; an unknown kind falls back; movement still
  works; frame path, tests and clean tree.
