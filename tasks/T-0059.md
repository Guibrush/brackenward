# T-0059 — Wave readout and a Start Wave control

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2E — playability
Status: open

## Goal

The player decides when a wave begins, and can see where they are: wave 3 of 6, phase, what is
left on the board.

Today waves start the instant a level opens, so a player cannot build before the first one.

## Context

- `src/gameplay/arena.gd` — `start_wave(index)`, `end_wave()`, `begin_wave()`, phase state,
  `plan_summary()`, `waves_cleared()`, `level_wave_count()`, `phase_changed` signal
- `src/ui/build_panel.gd` — the panel to extend; same input abstraction, same refusal style
- `src/ui/boot.gd` — sets `start_first_wave`; the **autostart path must keep starting waves**
  or `smoke.ps1` will have no waves to measure
- `docs/CHARTER.md` — planning between waves is free; during a wave towers are locked

## Scope

1. A **wave readout**: current wave / total, the phase (build or wave), and enemies
   remaining in the current wave when one is running.
2. A **Start Wave** action, available only in the build phase; it starts the next wave and is
   refused with a printed reason when a wave is already running or there are no waves left.
3. **A player-run level opens in the build phase.** `start_first_wave` stays true only for
   the `--autostart` gate path; a player's run waits for the button.
4. When the last wave of a level clears, the existing completion path runs unchanged.
