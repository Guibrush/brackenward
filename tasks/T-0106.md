# T-0106 — Regenerate grunt, runner and shieldback

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Three enemy sets, 4 directions, using `art/director`'s exact archetypes and sizes. The
first batch was rejected (crown crop + grunt/runner silhouette clash) and deleted. These
are new generations, not post fixes.

## Route and canvas

- `create_character`, standard, 4 directions (south, west, east, north), transparent,
  3 calls, no regenerations.
- Generate at **size=24** for each. The tool pads the canvas (~33×33); **pad/crop the
  transparent canvas to 32×32 around the content**, preserving every content pixel and
  leaving clear margins. No content may touch row 0 or any edge.
- Post: palette snap to ≤12 locked tones, 1px `#1b1a26` outline, binary alpha, 0 ground
  pad, 1 connected component, no holes.
- Credits fund the calls ($9.87); plan generations stay at 4 and are not the gate.

## Save and register

`art/candidates/enemies/<kind>/idle/{south,west,east,north}.png`, 32×32 each. One
manifest entry per kind (`type: character`, `directions: 4`, `frames` list,
`placeholder: true`, `status: candidate`, prompt, generator, seed/job, spend, metrics,
`content_bbox`). Run `powershell.exe -NoProfile -File scripts/gate/assets.ps1`.

## Constraints

- Three calls, no regenerations. A failed silhouette is reported, not re-spent.
- If funding/tool fails, stop with the exact response.
- No other enemies, animation, towers, wiring, git.

## Definition of done

Balance/spend, three sets with per-direction metrics (tones, off-palette, alpha, holes,
pad, bbox, margins), manifest entries, gate, one recommendation per enemy.
