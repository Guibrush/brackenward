# T-0049 — Non-level nodes do something

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2C — run flow
Status: open

## Goal

Every non-level node type on the map now has an effect when entered, instead of refusing as
"not implemented".

## Context

- `src/gameplay/run_flow.gd` — the session; node types are recognised and refused there
- `src/systems/store.gd` — stock of five, tier-weighted, second-half guarantee, reroll
- `src/systems/offers.gd` — the offer set and the shared reroll machinery
- `src/systems/inventory.gd` — where a purchase lands
- `src/systems/run_state.gd` — gold and HQ
- `docs/design/systems/nodes.md`, `store.md`, `hidden-rules.md` — the intended effects

## Effects, from the design tables

| Node | Effect |
| --- | --- |
| `store` | Generate stock from the run seed, layer and visit. Buying spends gold and puts the item in the inventory, respecting the inventory cap. Reroll obeying its per-site switch and cost |
| `rest` | Heal the HQ by a data-driven amount, never above its maximum |
| `treasure` | Grant gold, data-driven amount |
| `event` | Offer N items; choosing one adds it to the inventory, once |
| `high_stakes_event` | **Blind**: the roll happens when the node is chosen and the outcome is revealed on entry — HQ damage, or a tower tier upgrade. The player must not be able to see which before entering |
| `boss_preview` | Reveals the boss; no state change beyond that |

Nothing here needs a screen. Every effect must be reachable through the session's API and
observable in headless output.

## Definition of done — with planted failures

1. `--check-only` per script, pasted.
2. A headless demo walking a seeded route that includes **at least one of each node type**;
   print what each did (gold delta, HQ delta, item acquired, roll outcome). Force node types
   with the map's `forced_types` if a natural seed is awkward.
3. **Planted failure A — the blind roll is blind:** show that the outcome is not readable
   from the map before entry (`knowledge()` for a high-stakes node contains no outcome), and
   that it is fixed once and not re-rolled if the node is re-read.
4. **Planted failure B — purchase guards:** buying without enough gold is refused with a
   printed reason and nothing enters the inventory; buying past a switched-on inventory cap
   is refused too.
5. **Rest cannot overheal:** healing at full HQ changes nothing, printed.
6. `tests.ps1` 5/5 and a short `smoke.ps1` keeping `stuck 0` with no error lines.
