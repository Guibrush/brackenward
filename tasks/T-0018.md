# T-0018 — Narrow the G2.5 placeholder exemption to raw evidence

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 1b — unblocks the asset gate
Status: open

## Goal

`scripts/gate/assets.ps1` scans every PNG in the manifest except entries that are
the unmodified generator dump. Today the skip is `placeholder: true`, which at G2
exempts everything, so G2.5 passed while scanning a single image (L-031).

## The change

Replace the placeholder skip with a `status -eq 'raw-evidence'` skip. Every other
PNG is scanned for palette conformance, placeholders included. Do not change the
G2.5 wording, and do not reintroduce an exemption keyed on the placeholder flag.

## Definition of done — the failure must be observed

1. **Planted failure.** Put one deliberately off-palette pixel into a placeholder
   sprite (`assets/art/towers/arrow/idle/south.png` is the obvious candidate — it is
   `placeholder: true`). Run `assets.ps1`; it must **exit 1** and name both the asset
   and the offending colour. Paste the output.
2. **Restored pass.** Revert the pixel byte-for-byte, re-run, exit 0. Paste the
   output and confirm the file hash matches the pre-test hash.
3. Report how many images are now scanned versus before the change — a number, not
   a verdict.
4. Confirm raw-evidence files are still skipped, and say which files those are.

## Do not

- Do not exempt by `placeholder` again, and do not add any second skip condition.
- Do not weaken the palette check to a tolerance or a subset of hexes.

## Return

The standard envelope with both runs' output, the scanned-image count, the hash
comparison, and `FILES TOUCHED`.
