# T-0075 — Square inventory slots with placed/hand borders

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2H — inventory interaction
Status: open

## Goal

The bar's slots become **squares**, one per item, and each shows whether that tower is **placed
in the level** or still **in hand** by its border colour. Placed towers stay in the bar.

## What the human decided

- Slots are square. Final art is the tower icon; today a text label is acceptable but the slot
  shape is square.
- **A placed tower still appears in the bar**, with a border that distinguishes it from one in
  hand. The bar and the board are two views of one object.
- Colours are exported settings, not constants.

## Scope

1. Square slot geometry, exported size, consistent spacing and page layout (8 per page unchanged).
2. Border colour by state: in hand, placed — and leave an obvious place for the third state the
   wave lock will need later. Export all colours.
3. Placed towers are listed, not hidden. The count in the group header should say which it means,
   or show both; say what you chose.
4. Clicking a slot still raises `tower_selected`, unchanged — drag and the info window are the
   next tasks.

## Constraints

- Write `src/ui/**` and `scenes/inventory_bar.tscn` only; no `src/systems/**`, `scripts/**`,
  `docs/**`, `project.godot`.
- **40 steps, last 8 reserved** for verification and the envelope.
- No git commands; `studio-lead` commits with `Agent: eng/gameplay`, `Task: T-0075`.
- Zero generations.

## Definition of done — one demo, one frame

1. `--check-only`, pasted.
2. A demo on the **real boot path** with pushed events: after the opening choice the slot is
   **square** (assert width equals height, within a pixel); a tower in hand has the hand border; place
   that tower and the same slot remains listed with the **placed** border; the colours come from the
   exports, proven by changing one export in the demo and seeing the slot follow.
3. **Planted failure:** make the bar drop placed towers and show the demo catching the missing slot.
4. **A rendered frame** of the bar with one placed and one in-hand tower, saved outside the repo,
   path reported.
5. `tests.ps1` 5/5 and short `smoke.ps1` unchanged.

## Return

The standard envelope with the frame path, the square and border evidence, the planted failure,
and `FILES TOUCHED`.
