# T-0060 — Player levels wait for Start Wave; autostart still starts them

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2E — playability
Status: open

## Goal

A player's level opens in the **build phase** and waits. The gate's `--autostart` path keeps
starting waves by itself, because `smoke.ps1` measures waves.

One file, one behaviour. Nothing else.

## The change

In `src/ui/boot.gd`:

1. `start_first_wave` **defaults to false** — a player's level waits for the Start Wave row the
   panel now offers.
2. It is forced **true only on `--autostart`**, in argument parsing.
3. The level-open path requires `start_first_wave and autostart`, so a stray inspector value
   cannot auto-start a player's level.
4. Update the doc comment and the `BOOT_LEVEL` printed fields to say which mode is in force.
