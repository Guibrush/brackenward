# T-0091 — Controller placement mode in the build panel

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2I — controller placement
Status: open

## Goal

Close the loop: with a gamepad (or keyboard), the player can focus the bar, pick a tower,
move a tile cursor over the build slots, confirm to place it, and dismiss to cancel. The
panel is already the level's single input reader; it drives the bar API from T-0090, so
no second input door is added.

## Modes

`src/ui/build_panel.gd` gains a control mode:

- **ROWS** (default): today's behaviour. `FOCUS_NEXT/PREV` moves the Start Wave focus.
- **BAR**: entered from ROWS by `MOVE_LEFT/RIGHT`. Those intents move the bar's focus
  (`bar.focus_tower(±1)`); `CONFIRM` calls `bar.activate_focused()` and, when a tower is
  armed, switches to TILES; `DISMISS` clears the bar focus and returns to ROWS.
- **TILES**: `FOCUS_NEXT/PREV` and `MOVE_LEFT/RIGHT` move a cursor over the **free**
  build slots (nearest slot in the pressed direction, staying in its 90° cone; no move
  when none); `CONFIRM` places the armed tower at the cursor's world position; `DISMISS`
  disarms and returns to ROWS. A successful `place_at()` from any path (mouse, drop,
  controller) resets to ROWS.

## Wiring and visibility

- `bind_inventory_bar(bar) -> bool` on the panel; the boot calls it in
  `_wire_level_panel()` (next to the other bar wiring) and reports it in `BOOT_WIRED`.
- A `ReferenceRect` cursor (`Cursor`), panel child, `mouse_filter = IGNORE`, hidden
  outside TILES, border colour/width exported, size exported (default 40 px). Position
  from the slot's world point through the panel's existing canvas transform (add the
  inverse of `_pointer_world`).
- Read-back for the demo: `control_mode() -> String` (`"rows"`, `"bar"`, `"tiles"`),
  `cursor_slot_name() -> String`, `cursor_rect() -> Rect2`.
- Pointer input keeps working unchanged in ROWS/TILES; a pointer confirm that places a
  tower also returns the mode to ROWS.

## Demo

`src/ui/tests/inventory_migration_demo.gd`, at the end of the placement walk and before
the movie block:

1. Take the placed tower back (panel method) and clear the selection.
2. Push a real `KEY_RIGHT`: `control_mode()` becomes `bar`, the bar's focused id is the
   tower, the focus frame is visible.
3. Push `KEY_ENTER`: the panel arms that tower, `control_mode()` becomes `tiles`, and
   `cursor_slot_name()` names a free slot.
4. Push one directional key (`KEY_UP` or `KEY_RIGHT`) and assert the cursor either moves
   to another free slot or stays (when there is no slot in that direction), never to an
   occupied one.
5. Push `KEY_ENTER`: the tower is placed on the slot the cursor named, the bar shows it
   placed, `control_mode()` is `rows`, and `cursor_rect()` is empty.
6. A dismiss case: take it back, `KEY_RIGHT`, `KEY_ENTER`, then `KEY_ESCAPE`; nothing is
   placed, the panel is disarmed, mode is `rows`.

Keep every existing case green (the walk currently ends with the tower placed again).
