# T-0099 — Post the accepted rime and beacon raws

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Apply `art/director`'s post pass to the two T-0098 raws and promote them to candidates.
No generation; zero spend.

## Post pass (exact)

For each of `art/candidates/tower-rime-candidate-t0098-raw.png` and
`art/candidates/tower-beacon-candidate-t0098-raw.png`:

1. Translate the whole sprite **down 1 px** (y → y+1), leaving row 0 empty and the base
   on row 63.
2. Complete a continuous 1 px `#1b1a26` outline on the outer silhouette (the director
   measured rime 75.7% and beacon 88.4% boundary ink before).
3. Change nothing else: same pixels otherwise, no palette change, no geometry.

Write the results to `art/candidates/tower-rime-candidate.png` (replacing the earlier
rime candidate) and `art/candidates/tower-beacon-candidate.png`. Keep both raws.

## Verify

- Rime: bbox x=[12,51] (w=40), y=[1,63] (h=63), 100% boundary ink, 7 tones, 0
  off-palette, binary alpha, 0 holes.
- Beacon: bbox x=[14,47] (w=34), y=[1,63] (h=63), 100% boundary ink, 9 tones, 0
  off-palette, binary alpha, 0 holes.
- A pixel diff against the raw must show exactly the translation plus the recoloured
  boundary pixels; report how many pixels changed.

## Register

Update `art/manifest.json`: the two candidate entries (placeholder true, status
candidate, prompt reference to T-0098, post_processing, the verified metrics, the raw
file), and credit ledger unchanged (no spend). Run
`powershell.exe -NoProfile -File scripts/gate/assets.ps1` (L-048; never `pwsh`).

## Constraints

- No generation, no other assets, no scene wiring, no git.
- If a metric does not match, stop and report rather than editing the rule.

## Definition of done

- Both candidate paths, metrics, pixel-diff counts, gate result.
- One recommendation: ready to wire all six, or not.

## Return

The standard envelope with paths, metrics, gate and `FILES TOUCHED`.
