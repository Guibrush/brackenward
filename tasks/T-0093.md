# T-0093 — Generate the ballista tower candidate

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Generate **one** tower sprite — the ballista — as the first of the five missing towers,
so the pipeline and the look can be judged before the batch spends the rest of the
budget. Do not generate any other tower or enemy in this task.

## Inputs

- `art/STYLE.md` (locked): 64×64, isometric 3/4, top-left light, 16-colour palette,
  selective 1px `#1b1a26` outline, roofed-tower fill (height ≥80% of the canvas, widest
  row ≥24 px, measured pad-free including the outline), no ground pad, ≤12 tones.
- `art/style/anchor.png` as the style reference. Upload it first (`get_upload_url`, free)
  because the style tools refuse local paths.
- `docs/design/systems/towers.md` for the ballista's identity, and `art/manifest.json`
  for the arrow tower's prompt/entry shape.
- `get_balance` before and after; if the required call cannot be funded, **stop** and
  report the balance rather than degrading to a different route.

## Generation

- Use the style-image route (`create_image_pro_flash`, 5 generations per call, anchor as
  the style reference; 64×64 transparent). If the tool refuses the 64×64 anchor into a
  64×64 canvas, crop the reference to 60×60 as the audit suggested and record that.
- Prompt: a ballista tower that reads distinctly from the roofed arrow tower at thumbnail
  size — wooden siege platform / large crossbow silhouette, same palette, top-left light,
  no ground. Write the exact prompt into the manifest entry.
- Post (free): crop the ground pad, palette snap with the workbench (≤12 tones), add the
  1px ink outline, verify binary alpha, 0 enclosed holes, no edge clipping, and the
  roofed-tower fill rule. Same checks the arrow tower records.
- If the candidate clearly fails the silhouette or fill rules, **one** regeneration is
  allowed within this task; a second failure stops and returns to `studio-lead` with
  what was spent.

## Register

- Save under `art/candidates/` (create it) or `art/style/candidates/`, and add a manifest
  entry with `id` (`tower-ballista-candidate`), `file`, licence, prompt, generator,
  `generations_spent`, `placeholder: true`, `status: "candidate"`, and the verified
  metrics. The asset gate must pass (`assets.ps1`).

## Constraints

- Budget: **10 generations maximum** (one Pro Flash call + one regeneration). Stop at
  the ceiling; do not retry more.
- No scene wiring, no enemy generation, no animation.
- No git commands; `studio-lead` commits with `Agent: art/pixel`, `Task: T-0093`.
- If anything fails — funding, upload, tool refusal, palette/fill — **stop and report**
  instead of working around it silently. The human will decide on more credit.

## Definition of done

- `get_balance` before/after, exact spend.
- The candidate path outside the shipping assets, prompt, metrics (tones, off-palette,
  fill, outline coverage, alpha, pad), and the manifest entry.
- `assets.ps1` pass.
- A clear recommendation: ship as the ballista, or regenerate, or stop.

## Return

The standard envelope with the candidate path, metrics, spend and `FILES TOUCHED`.
