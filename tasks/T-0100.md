# T-0100 — Promote the six tower sprites to shipping paths

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Move the five approved tower candidates into the shipping tree at
`assets/art/towers/<type>/idle/south.png` (type = ballista, mortar, rime, beacon,
bramble), matching the already-shipped arrow tower. Zero generation.

## Steps

1. Copy each `art/candidates/tower-<type>-candidate.png` to
   `assets/art/towers/<type>/idle/south.png`.
2. Update the manifest entry for each:
   - `file` = the new shipping path; `status` = `"shipped"`; `placeholder` = false;
   - `purpose` states it ships as the G2 `<type>` tower, approved by `art/director`
     on 2026-11-12;
   - keep the prompt, generator, metrics, post_processing and the `raw` reference.
3. Delete the five `art/candidates/tower-<type>-candidate.png` files (the shipping copy
   replaces them; the raws stay registered). Do not delete the raw files.
4. Update `id`? Keep the existing ids (`tower-ballista-candidate` etc.) or rename to
   `tower-<type>-idle-south` consistently with the arrow; pick one and say which. The
   arrow's precedent is `tower-arrow-idle-south`, so prefer the rename.
5. Run `powershell.exe -NoProfile -File scripts/gate/assets.ps1` (never `pwsh`).

## Constraints

- No generation, no edits to pixels, no scene wiring, no git.
- Every file under `art/candidates/` must remain either registered or absent.

## Definition of done

- Six shipped tower files (arrow + five) under `assets/art/towers/`, each with a manifest
  entry.
- Gate pass with the shipped set; list the files and entries.
- `git status --porcelain`.

## Return

The standard envelope with the promoted paths, the manifest ids and the gate result.
