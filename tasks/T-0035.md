# T-0035 — Rules and tuning tables

Owner: `design/systems`
Milestone: G2 — Vertical slice
Wave: 2B — blocks nothing, informs everything
Status: open

## Goal

The numbers the slice runs on, written down before code hardens around placeholders:
towers, upgrades, items, enemies, waves, economy and HQ. Everything here is a table in
`docs/design/systems/`, not code.

## Context

Read first:

- `docs/CHARTER.md` — run structure, scope budget (6 towers × 3 tiers, 20 items, 5
  enemies, 1 boss, 2 sub-bosses), pillars (1 beats 2 beats 3)
- `docs/gates/G2-vertical-slice.md` — what the slice has to demonstrate
- `docs/LESSONS.md` — L-030 (a target must be validated against the shortest/weakest
  case), L-035 (a runtime that exits 0 while printing errors)

## Deliverables, in `docs/design/systems/`

1. **towers.md** — the 6 towers, their identity in one line each, and a 3-tier table:
   damage, rate, range, cost, upgrade cost, and what the tier visibly changes. Tier
   deltas must be meaningful, not +10% filler.
2. **items.md** — 20 items that modify towers, each with slot/stacking rule, effect, and
   the tower classes it suits. No item may be strictly better than another at everything.
3. **enemies.md** — 5 normal enemies, 2 sub-bosses, 1 boss, with speed, health, armour or
   resist, and the player behaviour each is designed to punish.
4. **waves.md** — a wave curve per level archetype (opening, pressure, peak, boss), with
   the rule for how composition is generated from a level's parameters.
5. **economy.md** — gold per kill, per wave, per level; tower and upgrade costs; reroll
   cost; HQ health and the damage each enemy type deals. State the arithmetic: what a
   player can afford by wave N if they play averagely.
6. **reroll-and-offers.md** — how many offers, what weights them, what reroll costs.

## Constraints

- Markdown and tables only. No code, no scenes, no assets.
- Every number is a **placeholder for G2** and must be labelled as such in one line at the
  top of each file. The point is to make the slice tunable, not to be right first time.
- Where a number is a guess, say it is a guess and name what would settle it.
- No git commands; `studio-lead` commits with `Agent: design/systems`, `Task: T-0035`.
- Zero generations.

## Definition of done

1. All six files exist, each with a labelled placeholder banner and tables that parse.
2. **Arithmetic check:** the economy file shows at least one worked example — gold earned
   and spent over the first three waves of a level — and the totals reconcile.
3. **Sanity check:** name any two numbers that would break the loop if wrong in the wrong
   direction (e.g. tower cost versus gold per wave), and show the threshold at which the
   opening becomes unwinnable or trivial.
4. A single page, `README.md`, listing the six files and the one-line purpose of each.

## Return

The standard envelope with the file list, the worked example's totals, and the two
sanity thresholds.
