# T-0074 — Wire the tower window (carefully)

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2G — UI structure
Status: open

## Why this brief is written as a checklist

Two previous attempts to wire this window broke `boot.gd` — first a function signature deleted, then
calls to two functions that were never written — and both had to be reverted. **Parse after every
single edit**, not at the end. If an edit breaks the file, revert that edit and report it rather than
pressing on.

## State

- `src/ui/tower_window.gd` and `scenes/tower_window.tscn` exist and parse. They open for an instance,
  show identity/tier/equipped, offer equip (works on a tower in hand), tier-up and take-back, and are
  read-only during a wave using the arena's own sentence.
- Nothing mounts them.

## Checklist — one step at a time, parse between each

1. `src/ui/boot.gd`: add `tower_window_scene` export and `_tower_window` field, with docs.
2. Add `_mount_tower_window()` next to `_mount_inventory_bar()`: instantiate, name `TowerWindow`, add
   to the HUD after the bar, bind the session, print a `BOOT_HUD` line.
3. Add `_free_tower_window()` mirroring `_free_inventory_bar()`, and call it in `_release_run()`.
4. `_start_run()`: refuse to start a run when `tower_window_scene` is unwired, for the same reason the
   bar is refused.
5. `_wire_level_panel()`: give the window the arena; connect the bar's `tower_selected` and the panel's
   `tower_inspected` to one handler that opens the window for ids `>= 0`.
6. `src/ui/build_panel.gd`: add `signal tower_inspected(instance_id)` and emit it from selecting a
   **placed** tower only — not from placing one, or placing would pop the window.
7. `scenes/boot.tscn`: `tower_window.tscn` ext_resource + `tower_window_scene` property.
8. `_on_level_completed()`: close the window and unbind the arena.

## Definition of done — one demo, real events, one frame

1. `--check-only` after every edit; the final one pasted.
2. A demo on the **real boot path** with pushed events: click a tower in the bar → window opens with
   its tier; equip an upgrade → it leaves the bar's list and appears on the tower; equip to a tower
   still **in hand** works; tier-up spends gold and the window shows the new tier; click a placed
   tower → the window opens for it.
3. **Read-only during a wave:** start a wave, open the window, attempt equip, tier-up and take-back —
   each refused with a printed reason, gold and tier unchanged.
4. **A rendered frame** of the window over a level, saved outside the repo, path reported.
5. `tests.ps1` 5/5 and short `smoke.ps1` unchanged.
