# T-0030 — Failure demonstrations without touching the real tree

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 2A — process hardening
Status: open

## Goal

`scripts/gate/prove-failure.ps1` runs a failure demonstration against a **copy** of the
project, so an interrupted run can never leave the real tree mutated. Today a
demonstration is an in-place edit plus a promise to revert it; twice in one day the
reverting agent hit its step cap first, leaving `src/` deliberately broken in a tree
about to be committed from.

## Design (fixed by the human; implement it, do not redesign)

- Copy the project to a temp directory, excluding `.git/`, `.godot/`, `.mutation-backup/`
  and any existing sentinel. Report how many files were copied.
- Apply a **named mutation** from a registry inside the script — not an arbitrary
  callback, so every demonstration is reviewable in one file. At minimum:
  - `off-palette-pixel` — set one visible pixel of
    `assets/art/towers/arrow/idle/south.png` to `#FF00FF`
  - `assertion-2x-damage` — make `scripts/tests/cases/leak_damage.gd` expect twice
    `damage_per_leak`
  - `despawn-disabled` — replace the `queue_free()` body in
    `src/gameplay/lane_walker.gd` with `pass`
- Run the named gate **in the copy** (`<copy>\scripts\gate\<gate>.ps1`). The gate
  resolves `$StudioRoot` from its own location, so it must target the copy; verify that
  explicitly and fail loudly if the resolved root is not the temp directory.
- Assert the expected exit code (default 1). Print the exit code, the observed failure
  lines, and the mutation that produced them.
- **`finally` deletes the copy**, including on exception, on Ctrl-C and on a failed
  assertion. Nothing may survive in `%TEMP%`.
- Print the real tree's SHA-256 for each mutated path before and after the run, so a
  human can see it never changed.

## Constraints

- You may write `scripts/gate/prove-failure.ps1` and, if unavoidable, `scripts/lib/common.ps1`.
- Do not create the sentinel or `restore.ps1`; those are T-0031.
- Do not modify `src/**`, `assets/**`, `scenes/**` or `project.godot`. The whole point is
  that this script never writes to the real tree.
- No git commands; `studio-lead` commits with `Agent: eng/tools`, `Task: T-0030`.
- Zero generations.

## Definition of done — every line observed

1. `prove-failure.ps1 -Gate assets -Case off-palette-pixel` reports `assets.ps1` exiting
   **1** with the off-palette colour named. Paste it.
2. `git status --porcelain` is **empty** immediately afterwards. Run the whole
   demonstration **twice in a row**, pasting `git status` after each, both empty.
3. The real `assets/art/towers/arrow/idle/south.png` SHA-256 is identical before and
   after; print both.
4. **Exception path:** force a failure mid-run (an unknown `-Case`, or a gate script that
   does not exist). Show the error, then show the temp directory is gone and `git status`
   is empty.
5. The copy is deleted in `finally`, demonstrated by pointing at a temp root that no
   longer exists after the run.
6. `-Gate tests -Case assertion-2x-damage` and `-Gate smoke -Case despawn-disabled` also
   produce exit 1 in the copy, with the failure named. If a gate needs a long run, take
   the scene's short duration argument in the copy only — never in the real tree.

## Do not

- Do not fall back to in-place editing when a copy fails. If copying is impossible, fail
  loudly and report; a broken demonstration is better than a mutated tree.
- Do not raise or bypass any step cap.

## Return

The standard envelope with all six items' output, the copy file count, and
`FILES TOUCHED`.
