# T-0040 — The run map: nine layers of branching choices

Owner: `eng/systems`
Milestone: G2 — Vertical slice
Wave: 2B — core systems
Status: open

## Goal

A run is a generated map the player routes through: 9 layers between the start and the
boss, 2–3 nodes per layer, at least one **map** node per layer, and the boss level unique
and final.

## Context

- `src/systems/run_state.gd` — level index, gold, HQ; **do not edit it**, expose the map as
  a separate object it can carry
- `docs/design/systems/run-map.md` and `nodes.md` — being written by T-0038 in parallel;
  use their vocabulary, keep `PLACEHOLDER` numbers where they are absent
- `docs/CHARTER.md` — 5–10 levels, map reuse deliberate, same map may appear twice in a run
- `docs/LESSONS.md` — L-033, L-035

## Scope

- **Generation**: 9 layers, each 2–3 nodes, each layer containing at least one map-type
  node, boss node as the single final node.
- **Node types**: map, store, elite, boss preview, treasure, rest, event, high-stakes event
  — with weights, and a design that accepts new types without a refactor.
- **Reveal**: a node's type, dominant enemy types and active-tile count become visible when
  the map reveals that node (i.e. when it is a legal next choice). Wave composition is
  never stored on the map.
- **Selection weighting**: the immediately previous map has the lowest non-zero weight of
  being chosen again.
- **Determinism**: a seed reproduces a map exactly.

## Definition of done — with planted failures

1. `--check-only` output pasted for every script touched.
2. Generate **200 runs** with fixed seeds and assert every invariant: 9 layers, 2–3 nodes
   each, ≥1 map node per layer, exactly one final boss, no node unreachable from the start.
   Paste the counts.
3. Same seed twice ⇒ identical map; different seeds ⇒ different maps. Show the hash or
   serialised form of both.
4. **Planted failure A:** force a layer with no map node and show the generator rejecting
   it with a printed reason instead of returning a bad map.
5. **Planted failure B:** force the previous-map weight to 100% and show the weighting
   assertion failing.
6. The reveal rule is observable: print what a player knows at layer 1 versus layer 5 —
   visible node types and dominant enemy types, never wave composition.

both planted failures, and `FILES TOUCHED`.
