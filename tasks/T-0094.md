# T-0094 — Generate the mortar and rime tower candidates

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Generate the next two tower candidates — **mortar** and **rime** — using the same route
and post-process as the approved ballista. One call each; validate each before spending
the next.

## Inputs

- `art/STYLE.md`, `docs/design/systems/towers.md`, the ballista manifest entry
  (`tower-ballista-candidate`) for the prompt/route/metrics shape, and
  `art/style/anchor.png` as the style reference (already uploaded as
  `upload:25763f10-f6ff-47c2-8f2e-d9d0a7a82df3`; reuse it if the tool accepts the id).
- `get_balance` before, between and after the two calls.

## Each candidate

- `create_image_pro_flash`, 64×64, transparent, anchor as style reference, locked 16
  palette passed as a list, `max_colors: 12`.
- **Mortar**: squat, wide, heavy silhouette with a clear upward-facing mortar tube —
  visually distinct from both the roofed arrow tower and the ballista's open frame.
- **Rime**: tall, narrow, frost/ice tower with crystal spires and a cold palette drawn
  only from the locked 16 (slate/deep teal/stone/parchment), distinct at thumbnail.
- Post: crop pad, palette snap if needed, 1px `#1b1a26` outline, binary alpha, no
  enclosed holes, no clipping, roofed-tower fill rule.
- Save under `art/candidates/`, register as `tower-mortar-candidate` and
  `tower-rime-candidate` (placeholder true, status candidate, prompt, generator,
  generations_spent, metrics, raw evidence), and pass `scripts/gate/assets.ps1`.

## Constraints

- **Budget 10 generations, two calls, no regenerations.** If the first candidate fails
  the style/fill rules, **stop before the second call** and report; do not improvise.
- If `get_balance` or a call refuses for funding, stop and report the balance.
- No other towers/enemies/animation, no scene wiring, no git.
- No workaround of a failed tool or upload; stop and report.

## Definition of done

- Balance before/between/after and exact spend.
- Two candidates (or one, with the stop reason) with paths, prompts, metrics, manifest
  entries and the asset gate passing.
- Per-candidate recommendation: ship / regenerate / stop.

## Return

The standard envelope with paths, metrics, spend and `FILES TOUCHED`.
