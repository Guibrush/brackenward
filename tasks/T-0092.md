# T-0092 — Reconcile the art ledger and register the evidence files

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Why

The PixelLab audit (2026-11-12) found the manifest and the vendor disagree: the manifest
records **8** generations, `get_balance` reports **16** used. Six generation outputs on
disk have no manifest entry, and `docs/ASSETS.md` claims `assets.ps1` checks both
directions when it iterates manifest entries only.

## Scope — zero generation

1. **Every PNG under `art/style/` and `assets/art/` that has no manifest entry** is either
   registered or deleted before this task ends. Prefer registering the historical
   evidence (candidates and raws) so the record survives; a file that is pure scratch is
   deleted. Each new entry needs `id`, `file`, `license`, `purpose`, `status`
   (`probe` / `raw-evidence` / `variant`), and `placeholder: true` where the palette does
   not conform.
2. **Record the ledger honestly** in `art/manifest.json`: the vendor counter is 16 and
   the manifest records 8. Add a top-level `generation_ledger` block with the vendor
   total, the recorded total, the unattributed count, the source (`pixellab.get_balance`,
   date), and a short note that the early jobs' individual costs are not recoverable from
   the vendor API. Do not invent per-asset counts to make the numbers agree; mark unknown
   values as unknown.
3. **Run the asset gate**: `powershell -NoProfile -File scripts/gate/assets.ps1` must pass
   after the edits. If a registered raw file's palette fails, say so with the exact
   colours and either keep it unregistered (delete) or correct `placeholder` per the
   schema, not by editing the gate.
4. **Report two docs defects** without editing them:
   - `docs/ASSETS.md:3-5` says the gate checks file→manifest; `assets.ps1` checks
     manifest→file only;
   - `art/STYLE.md:92` says "4 samples, 6 generations", which matches no measured count.
5. Do not generate, do not touch `assets/art` sprites, do not edit the gate or docs.

## Constraints

- Write `art/manifest.json` and delete/keep files under `art/style/` only. The
  `assets/art` shipped sprite is not yours to change here.
- **20 steps**, last 5 reserved for verification and the envelope.
- No git commands; `studio-lead` commits with `Agent: art/pixel`, `Task: T-0092`.
- Zero generations, zero spend.

## Definition of done

1. `assets.ps1` pass, pasted.
2. The manifest's `generation_ledger` block and a list of every registered/deleted file.
3. The two documentation defects reported with file:line.
4. `git status --porcelain` and a clean-tree statement.

## Return

The standard envelope with the ledger totals, the file dispositions, the gate result and
`FILES TOUCHED`.
