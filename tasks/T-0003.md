## Goal

The public repository `brackenward` exists with `main` and `dev`, protection applied,
and the first CI run triggered. After this task the project stops being a local
folder and starts being a repository with an enforced process.

- `scripts/git/init-repo.ps1` — the sanctioned entry point. Read it fully before running it; it documents its own order of operations and refuses to proceed in several safe ways.
- `scripts/git/protect.ps1` — what protection it applies to `main` and `dev`

- **Description, verbatim:** `Run-based tower defence roguelike in Godot 4 — a prototype made with AI.`

- You may write: `.github/**` only if the script creates or modifies something there. Do not edit `docs/**`, `scripts/**`, or `project.godot`.
- Budget: no paid generation. This task costs nothing.

## Definition of done

1. `init-repo.ps1` completed and printed a repository URL. Paste the full output.
2. `powershell -NoProfile -File scripts/gate/repo.ps1` exits 0, or its failures are reported verbatim. Paste the per-check lines: G1.1, G1.2, G1.3, G1.4.
3. `gh repo view --json visibility,name,defaultBranchRef` confirms public, `brackenward`, default branch `dev`.
4. `git log --oneline -1` and `git branch -a` show the initial commit and both `main` and `dev` on the remote.
5. The first CI run is described: `gh run list --limit 3` output, with run id, branch, and conclusion. It is acceptable for the run to be `in_progress` or `queued` — report the state you actually observe rather than waiting indefinitely.
6. If protection did not fully apply (the script warns rather than failing), report exactly which of G1.2/G1.3 failed and why. This is expected to be possible on the first pass, because the `gates` status-check context may not be known to GitHub until a run exists. Do not work around it by weakening protection.

## Do not

- Do not force-push, do not delete branches, do not change the default branch away from `dev`.
- Do not create a pull request; that is T-0005.
- Do not edit the gate scripts or `protect.ps1` to make protection pass.
- Do not push any file that the secret scan excludes or warns about.
