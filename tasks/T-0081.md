# T-0081 — The corner block is three things

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2H — inventory interaction
Status: open

## Goal

The top-left block contains **only**: the HQ health, the wave number, and the Start Wave
button. Remove the title, the phase and enemies-left text inside the wave line, the
armed/selected status line, the refusal sentence and the hint line.

## The three elements, exactly

| Element | Text |
| --- | --- |
| State label | `HQ %d/%d` (unchanged) |
| Wave label | `Wave %d/%d` — no phase, no "enemies left", no "every wave cleared" |
| Actions list | one Start Wave row, label always `Start Wave` |

Nothing else is drawn inside `Block/Margin/Column`. The block keeps its panel background
and margins.

## Scope

1. `scenes/build_panel.tscn`: delete the `Title`, `Status`, `Reason` and `Hint` nodes. The
   column is `State`, `Wave`, `Actions`.
2. `src/ui/build_panel.gd`:
   - remove the `title_path`, `status_path`, `reason_path` and `hint_path` exports and the
     writes to them in `_apply_copy()`, `_show_reason()` and `_sync_status()`;
   - `_sync_status()` goes away; `status()` stays for the log line and the demos (it no
     longer draws anything);

     caller); the sentence is no longer drawn;

     line and the demos read them;

     running or exhausted, draw that row dimmed with `label_colour` and no band/border, so

     `wave_phase_format`, `wave_remaining_format`, `wave_finished_text`,
