# T-0111 — Display the game at the style's 2× scale

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Why

`art/STYLE.md` says a 32 px board is shown at **2× in a 1080p window**. The project has
no display block, so Godot's default 1152×648 window runs the game at 1×: a 32 px enemy
is 32 screen pixels and is hard to see or judge. The sprites are correct; the presentation
is not.

## Change

Add a `[display]` section to `project.godot`:

```ini
[display]

window/size/viewport_width=960
window/size/viewport_height=540
window/size/mode=3
window/stretch/mode="canvas_items"
window/stretch/aspect="keep"
window/stretch/scale_mode="integer"
```

- **960×540 logical, fullscreen, integer scaling**: on a 1080p display this is exactly
  2×; on taller displays the integer factor is chosen (2 at 1440p, 4 at 4K) with bars
  rather than fractional blur.
- The UI is anchored, so the corner block, bar, map screen, choice modal and tower window
  should lay out at 960×540. Check each one; the bar's 8 square slots and the 320 px tower
  window must still fit.
- Do not change any sprite, scene size, or gameplay constant. This is presentation only.

## Verification

- Run the game windowed at a known 1920×1080 surface and capture a frame (outside the
  repo): the corner block, the bar and at least one enemy sprite must be visible and
  crisp (nearest, no fractional scaling). Report the captured image size and the
  settings read back from `ProjectSettings`.
- Walk the menu → map → opening choice → level path; confirm no HUD element is clipped
  at 960×540 (report row count/rects if unsure).
- Run the tower window and map screens if practical; report any element that no longer
  fits.
- `tests.ps1` 6/6; `inventory_migration_demo` headless green (it sets its own
  root.size=1152×648; say whether that still works with the new project viewport).
- `git status --porcelain` and a clean-tree statement.
- If fullscreen makes the windowed demos/frames impossible, use `--resolution 1920x1080`
  for the capture and say so.

## Constraints

- Write `project.godot` only (plus the generated frame outside the repo). No scripts,
  scenes or assets.
- **20 steps**, last 5 reserved; no git; zero generations.

## Definition of done

Settings pasted, frame path/size, the HUD checks, tests 6/6 and a clear pass/fail.
