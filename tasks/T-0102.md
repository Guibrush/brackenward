# T-0102 — Generate the grunt, runner and shieldback sprite sets

Owner: `art/pixel`
Milestone: G2 — Vertical slice
Wave: 2J — art integration
Status: open

## Goal

Three static enemy sets, 4 directions each, for **grunt**, **runner** and
**shieldback**. No animation. Each is one `create_character` call at 32×32 with 4
directions (south, west, east, north), then post-processed per direction.

## Inputs

- `docs/design/systems/enemies.md` for identity and behaviour; `art/STYLE.md` for the
  palette, 1px ink outline, top-left light and the 32×32 character canvas.
- `art/style/anchor.png` for style reference if the tool accepts a reference; the
  standard `create_character` route is the cheap one and does not take it — say which
  route ran.
- `get_balance` before/after; credits fund the calls (plan generations stay at 4, as
  proven by T-0096..T-0099).

## Prompts

- **Grunt**: a small, hunched humanoid grunt; simple silhouette, the calibration
  enemy; single mass, readable at 32 px.
- **Runner**: lean, forward-leaning fast creature; clearly lighter and more angular
  than the grunt.
- **Shieldback**: bulky creature with a hard shield/plated back; the armour must read
  in silhouette from the back/top, not from a colour change only.

Each: transparent background, 4 directions, 32×32, palette-consistent with bracken
dusk, strong top-left light, no ground/plinth/shadow ellipse.

## Post, per direction

Palette snap to ≤12 locked tones, 1px `#1b1a26` outline on the outer silhouette,
binary alpha, 0 ground-pad pixels, no clipping, no detached fragments. Save four files
per kind under `art/candidates/enemies/<kind>/idle/{south,west,east,north}.png`.

## Register

One manifest entry per kind: `type: character`, `directions: 4`,
`frames: [the four paths]`, `placeholder: true`, `status: candidate`, prompt,
generator, seed/job, spend, and the metrics. Run
`powershell.exe -NoProfile -File scripts/gate/assets.ps1` (never `pwsh`).

## Constraints

- Three calls, no regenerations. If one output fails the rules, report it; do not
  spend another.
- If funding/upload/tool fails, stop and report the exact response; credits are $9.87.
- No towers, no other enemies, no animation, no scene wiring, no git.

## Definition of done

- Balance/spend; three sets (or the failure) with paths and per-direction metrics.
- Manifest entries, gate pass.
- One recommendation per enemy.

## Return

The standard envelope with paths, metrics, spend and `FILES TOUCHED`.
