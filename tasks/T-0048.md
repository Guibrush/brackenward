# T-0048 — Walk a route: nodes, levels, boss

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2C — run flow
Status: open

## Goal

Something owns the run's progression: it holds the map, the run state and the inventory, and
it moves the player from node to node — entering a level, returning to the map on
completion, and finishing the run on the boss.

## Context

- `src/systems/run_map.gd` — `generate(seed)`, `is_visible()`, `is_selectable()`,
  `knowledge()`, `enter()`, `route()`, `is_complete()`, `max_levels()`
- `src/systems/run_state.gd` — ADR-0006: no level count, `complete_level()`, `win_run()`,
  `damage_hq()`

- `docs/adr/0006-run-level-count.md`

## Scope

1. **A run session object** holding map + run state + inventory, with one entry point to
   start a run from a seed and one to enter a node.
2. **Level-type nodes** (`map`, `elite`) start a level: the arena receives the level index,
   HQ and gold from the run state, and the elite flag from the node.
3. **On level completion** the arena's completion returns control to the session, which
   calls `complete_level()` exactly once per level and returns to the map.
4. **Boss node completion** ends the run with `win_run()` — the session calls it, not the
   arena.
5. **Refusals are loud and printed:** entering a node that is not visible or not
   selectable, completing a level that was never entered, entering a node after the run
   has ended.
6. **Non-level nodes are out of scope here** — `store`, `rest`, `treasure`, `event`,
   `high_stakes_event`, `boss_preview` are recognised and refused with "not implemented"
   rather than crashing. T-0049 implements them.
