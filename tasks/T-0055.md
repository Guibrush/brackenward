# T-0055 — The gate measures the session; the game boots into the menu

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 2D — entry point
Status: open

## Goal

Two changes that only work together, per `docs/adr/0007-smoke-measures-session.md`.

## 1. `smoke.ps1` reads the session

The boot now prints, once, at quit:

```
BOOT_SESSION {"seconds": <elapsed>, "runs": <n>, "restarts": <n>}
```

- When that line is present, `smoke.ps1` compares its `seconds` against the existing 298 s
  threshold — the same comparison it makes today, against a different number.
- When it is absent, fall back to `ARENA_SUMMARY.seconds` so the script still works against a
  scene run directly.
- **Print which source it used** in the gate's own output, so a silent fallback cannot
  quietly weaken the criterion.
- `G2.1.2` (no error lines) and `G2.1.3` (`stuck == 0`) keep reading `ARENA_SUMMARY` — those
  are properties of a level, and the last level is the right place.
- The 300 s constant stays 300 s, still not settable by any flag.

## 2. Point the game at the boot scene

- `project.godot`: `run/main_scene` → `res://scenes/boot.tscn`.
- Then a real 300 s `smoke.ps1` run must pass **4/4**, with `BOOT_SESSION` naming the session
  depth and the last arena's `stuck` at 0.

## Constraints

- Write `scripts/gate/smoke.ps1` and `project.godot` only.
- Do not change the 300 s requirement, the error-line rule, or the `stuck` rule.
- **40 steps, last 8 reserved** for verification and the envelope.
- No git commands; `studio-lead` commits with `Agent: eng/tools`, `Task: T-0055`.
- Zero generations.

## Definition of done — with a planted failure

1. A **300 s** run: 4/4, showing the source line (`session`), the session seconds, `stuck 0`,
   and zero error lines. This is the criterion, so it must be the full duration, not a probe.
2. **Planted failure:** remove or blank `BOOT_SESSION` in a **copy** of the boot and show
   `smoke.ps1` falling back, printing `source: arena`, and still judging honestly on that
   number. Restore; the real tree unchanged by hash.
3. A short `-Duration 20` run still behaves as before: checks 1–3 pass, check 4 fails by
   design.
4. `tests.ps1` 5/5, and the game still launches: a headless run of the boot scene with no
   flags reaches the menu and exits cleanly on `--quit-after`.
