# T-0082 — Shrink the corner block to its text

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2H — inventory interaction
Status: open

## Goal

The top-left block is a fixed 280 px wide box. Make it wrap the three lines it draws: its
width should be the longest of `HQ 10/10`, `Wave 1/6` and the `Start Wave` row, plus the
panel margins. No empty space to the right.

## Change

1. `scenes/build_panel.tscn`: the `Block` `PanelContainer` has `offset_left = 12`,
   `offset_right = 292` (280 px), `offset_top = 12`, `offset_bottom = 12`. Set
   `offset_right = 12` so the control takes its combined minimum width from the column
   instead of the fixed 280. Leave the top/left anchors and the margins as they are. If the
   container needs a floor, use its minimum size - do not add a hardcoded width.
2. `src/ui/build_panel.gd`: the action row's `Label` sets
   `autowrap_mode = AUTOWRAP_WORD_SMART`, so it reports no text width and the min-size
   block collapsed until `Start Wave` broke into `Start` / `Wave`. Remove that line; a row
   is one short action on one line. This is the required second half of the shrink: without
   it the narrow box is worse than the wide one.

Nothing else changes: no copy, no colours, no demo.
