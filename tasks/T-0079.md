# T-0079 — Drop a tower from the bar onto the board

Owner: `eng/gameplay`
Milestone: G2 — Vertical slice
Wave: 2H — inventory interaction
Status: open

## Goal

The panel's half of drag-and-drop: one method that takes the bar's drop (`instance_id`,
viewport point) and places that tower on the build tile nearest the release point. The boot
wiring is T-0080; this task proves the receiver on the real boot path by handing it the
exact payload the bar raised in T-0078.

## Contract

```gdscript
func drop_tower(instance_id: int, screen_point: Vector2) -> bool
```

- `screen_point` is viewport coordinates, the space `tower_dropped` carries. Convert with
  the panel's own `_pointer_world()`, never with a second transform.
- Refuse, with the panel's existing `_refuse_action()` sentence, when:
  - no arena is bound;
  - the point is claimed by an overlay (`is_point_claimed`, i.e. the bar) — the release
    was not over the board;
  - the instance is unknown or already **placed**;
- Otherwise ensure that instance is the armed one (the drag's press already selected it,
  so this is a fallback, not a second selection path), convert, and call `place_at()`.
  Placement cost, the wave lock, the refusal sentence and the `tower_placed` signal stay
  exactly where they are: this method adds a door, not a second rule.
- Return whether a tower was placed.

Do not open the tower window from here. Do not touch the bar or the boot.

## Scope

1. `drop_tower()` in `src/ui/build_panel.gd`, next to `place_at()`, documented as the
   receiver of `tower_dropped`.
2. `src/ui/tests/inventory_migration_demo.gd`: after the T-0078 drag case (the tower is in
   hand and the release point is recorded), hand the recorded drop to the panel and prove:
   - a tower stands on the **nearest free build tile to the release point**, checked
     against the arena's own slot list (not against what the panel says);
   - the bar's slot now reports `placed` and the placed border colour;
   - gold is unchanged and the panel's selection is the placed tower;
   - a second `drop_tower()` for the same id is refused and places nothing;
   - a drop whose point is inside the bar is refused before the arena is asked
     (`refused_count()` unchanged) and places nothing;
   - take the tower back with the panel's own take-back, so the remaining cases and the
     acceptance frame run exactly as they do today (`_bar.slot_state` back to `in_hand`).
3. Keep every existing case green.
