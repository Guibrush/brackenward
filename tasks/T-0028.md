# T-0028 — Count N/A in the gate summary

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 2A — small unblock
Status: open

## Goal

`audio.ps1` prints `[N/A ]` with a reason but never adds it to the results, so a run
of six checks reports "4 pass" and silently omits two. A reader cannot tell whether
those checks ran.

## Work

1. Add `n/a` to the status vocabulary in `scripts/lib/common.ps1`, counted as a
   **fourth number** in every summary line, alongside pass / fail / blocked.
2. Leave exit-code semantics untouched: `n/a` is neither pass, fail, nor blocked, and
   must not change the process exit code by itself.
3. Apply it everywhere a summary is printed, not only in `audio.ps1` — the vocabulary
   lives in the shared library, so the summary format changes once.

## Context

- `scripts/lib/common.ps1` — `Add-Result` and `Complete-Gate`
- `scripts/gate/audio.ps1` — the only current producer of N/A; see how it prints the
  reason and the trailing list
- `docs/LESSONS.md` — L-021 and L-031: a check that cannot be seen is a check that
  cannot be trusted

## Constraints

- You may write `scripts/lib/common.ps1` and `scripts/gate/**` only.
- Do not change any criterion's meaning, any threshold, or any exit code.
- No git commands; `studio-lead` commits with `Agent: eng/tools`, `Task: T-0028`.
- Budget: 0 generations.

## Definition of done — with a planted failure

1. `audio.ps1` on the current tree prints a summary containing `n/a` and a non-zero
   count, e.g. `2 pass, 0 fail, 0 blocked, 2 n/a`. Paste it.
2. Every other gate's summary shows the same four fields, with `0 n/a` where nothing
   is inapplicable. Paste one example from a different gate.
3. **Planted failure:** construct a run where an N/A check is the *only* thing that
   would hide a problem — for example a manifest whose single entry is a bed with
   `loop: true` removed so seam checking becomes N/A — and show the summary reporting
   it as `n/a`, not as a pass. Then restore.
4. Exit codes unchanged: show that the audio gate still exits 0 with N/A present, and
   that a failing check still exits 1.

## Return

The standard envelope with each summary pasted, the exit-code evidence, and
`FILES TOUCHED`.
