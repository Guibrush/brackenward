# T-0026 — Real smoke check

Owner: `eng/tools`
Milestone: G2 — Vertical slice
Wave: 2A — critical path
Status: open

## Goal

`scripts/gate/smoke.ps1` runs the main scene headless for 300 s and fails when the
scene misbehaves. It currently cannot do either, so G2.1 reports `blocked`.

## Critical detail, already measured

The arena scene **exits 0 even when it is broken**: the run timer quits cleanly and
the despawn watchdog only calls `push_error`. With the walker's despawn handler
disabled, the run still exits 0 while printing three `ARENA_STUCK` lines and three
`ERROR:` lines. A gate that trusts `$LASTEXITCODE` would pass a broken scene.

So the pass condition is: exit 0 **and** no `ERROR:` lines **and** `"stuck": 0` in
the final `ARENA_SUMMARY`.

## Work

1. Set `run/main_scene` in `project.godot` to `res://scenes/main.tscn` — that file is
   yours and only yours.
2. Implement `smoke.ps1`: run the scene headless for 300 s, capture stdout, fail on a
   non-zero exit, on any `ERROR:` line, or on a non-zero `stuck` count in the summary.
   Report the numbers it read, not just a verdict.
3. Keep it cheap and deterministic: no window, no network, one scene.

## Definition of done — with a planted failure

1. Clean run passes (300 s) and prints the summary values it relied on.
2. **Planted failure:** disable the walker's despawn handler, run smoke again, and
   show it exiting 1 with the reason quoted from the output. Restore and show the pass.
3. Show that a scene which exits 0 but prints `ERROR:` is reported as a failure, not a
   pass — that is the case the old assumption would have missed.
4. Missing scene still reports `blocked` (exit 3), never `pass`.
